# DoneSpec v1.0 launch assets

These files are launch assets for a DoneSpec v1.0.0 release.

Publication has happened through the v1.0.0 release. These drafts are preparation material for maintainers to review, edit, and paste into the appropriate channels after the release gates pass.

Keep every claim conservative:

- DoneSpec validates explicit contracts, not semantic correctness.
- DoneSpec does not guarantee code correctness.
- DoneSpec does not replace tests, CI, or human review.
- DoneSpec is not an orchestration platform, AI framework, SaaS, agent runtime, workflow engine, or LLM tool.
- DoneSpec is the deterministic completion layer for AI coding agents.

Primary positioning:

```text
AI agents say tasks are done.
DoneSpec verifies they actually are.
```
